How to read this screen

Nodes send batches over HTTP. The receiver only queues them (fast reply), validator threads check every record in parallel, and a single DB writer thread saves them in groups. Every record is accounted for: received = stored + duplicates + rejected. Stress-test (drill) data is stored but not analyzed. The analytics re-run in a pool of worker processes whenever new cases arrive.
